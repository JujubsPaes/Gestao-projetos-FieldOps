# Atividade 04 — Cronograma do Projeto FieldOps

## Objetivo

Elaborar o cronograma do **FieldOps — Plataforma de Inspeção em Campo**, organizando as principais atividades do projeto, suas dependências, estimativas de duração, responsáveis e marcos.

## Estrutura do cronograma

O cronograma foi elaborado com **74 itens**, sendo **68 atividades** e **6 marcos**.

As atividades foram agrupadas nas seguintes frentes:

- Gestão do Projeto;
- API REST e Dados;
- Interface Administrativa Web;
- Aplicativo Mobile;
- Integração e Qualidade;
- Validação e Encerramento.

## Premissas utilizadas

- As durações foram estimadas em **dias úteis**.
- O cronograma utiliza **semanas relativas**, pois a documentação disponível não define uma data oficial de início.
- Os responsáveis são apresentados por **papel/equipe**, já que os nomes individuais dos responsáveis não estão definidos na documentação.
- As dependências representam a ordem lógica necessária para que as entregas do MVP sejam integradas e validadas.

## Principais marcos

- Planejamento inicial aprovado;
- API principal disponível para integração;
- Fluxo administrativo web completo;
- Fluxo mobile completo e operação offline disponível;
- MVP integrado e validado;
- Projeto FieldOps encerrado.
